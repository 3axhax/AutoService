# Девятое серверное ревью — 2026-11-03

## Результат

Новых подтверждённых замечаний в проверенных путях не найдено. SR8-1/SR8-2 остаются исправленными: formatter задаёт optionId по типу параметра, model.saveOptions не преобразует текст в ID; отправка Excel больше не зависит от непустого справочника.

## Проверенный объём

- Согласованность normalizer → formatter → setOptions/saveOptions для INPUT/GRAPH_INPUT и SELECT/SELECT_LIST/COMPOSITE_LIST. Проверены все production-вызовы setOptions: создание и редактирование используют общий formatter. Передача транзакции и hooks сохранены, ID/количество/группировка составных операций не потеряны.
- Экспорт с пустым/непустым справочником, базовые и динамические колонки, фильтры даты/работника/параметров, использование @Res и завершение отправки. Повторно проходят HTTP/XLSX-регрессии пустого справочника с заказом и без него.
- Scalar/bulk delete: DTO, дубликаты, поиск в компании, права на весь набор, повторное чтение после блокировки, row locks, individualHooks и проверка числа удалённых строк. Порядок owner locks согласован между пакетными операциями; одиночные записи/закрытие используют тот же advisory-протокол. Регрессии обеих очередностей закрытия смены проходят.
- Выбор общего/уточнённого тарифа, сохранение количества/скидки и вызов общего пакета сервером; нормализация, зависимости и доступность параметров.
- Защита проверенных controllers, RolesGuard/фактические роли, регистрация и сессии, scoped-чтение пользователей/настроек. Проверена совместимость затронутых ответов с текущими клиентскими thunk/reducers.

## Проверки и границы

В контейнере проходят 21 suite / 210 серверных тестов и npm run build. Отдельно проходят 36 pricing-тестов и 43 клиентских регрессионных сценария. git diff --check проходит. Контейнеры client/server работают, PostgreSQL healthy.

Исходники приложения, схема, конфигурация и рабочие данные не менялись, обновлена только документация ревью. Новые постоянные тесты или дополнительные исправления в этом проходе не добавлялись. Полный browser + real API + DB E2E, аудит исторических записей/старых ложных optionId и нагрузочные испытания не выполнялись. Результат означает отсутствие новых подтверждённых дефектов в указанном объёме, а не доказательство отсутствия всех ошибок проекта. Приёмка задачи, коммит/push и доставка не выполнялись.
