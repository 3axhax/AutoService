# Тестовые данные для проверки формирования цены

Источники:

- исходный прайс: `testData/Стоимость услуг.xlsx`, лист `Лист1`;
- нормализованный прайс для повторного использования: `price-list.json`.

## Правила расчёта

- Каждый сценарий — отдельный заказ для одного автомобиля.
- В заказе не более 8 колёс и не более 10 разных выполненных работ.
- Количество заказов не ограничивается.
- Первая таблица прайса содержит обычные шиномонтажные работы с ценой по категории техники.
- Во второй таблице «Шиноремонтные работы» ремонт колеса состоит из материала и выбранного способа выполнения работы.
- Цена шиноремонта рассчитывается как `стоимость материала + стоимость выбранной работы`.
- Холодная и горячая вулканизация — альтернативные способы; в один ремонт включается только выбранный способ.
- Префикс `от` не влияет на проверку: указанное число считается фиксированной ценой работы.
- Пустая ячейка означает, что услуга или способ ремонта недоступны.
- Для балансировки используется полный комплекс из скобок: 950 руб. с грузами и 1 150 руб. с гранулами за колесо.

## Негативные сценарии

1. Заказ с 9 колёсами должен быть отклонён.
2. Заказ с 11 разными видами работ должен быть отклонён.
3. Пустая ячейка внутри объединённого диапазона Excel не должна ошибочно означать отсутствие цены: значение объединённой ячейки распространяется на весь диапазон категорий.
4. Для пластыря, у которого действительно нет цены горячей вулканизации, нельзя выбрать горячий способ ремонта.
5. В одном шиноремонте нельзя одновременно начислить холодную и горячую вулканизацию.
6. Материал для шиноремонта должен начисляться ровно один раз на одну ремонтную операцию.
