# Результат

Дата: 2026-11-02.

Выполнен прямой запрос пользователя: два пароля в локальном игнорируемом testData/dev.json заменены и синхронизированы с локальной БД AutoService. По последующему уточнению итоговые пароли имеют ровно 8 символов, содержат латинские буквы обоих регистров и цифры. Использован криптографический генератор, значения различаются. В БД сохранены bcrypt-хеши с cost 10.

Обновление users.password выполнено транзакционно с проверкой прежнего хеша и однозначного соответствия id/email. JSON записан атомарной заменой с правами 0600. Игнорируемые защищённые копии исходных значений проверены; секреты не выводились в терминал и не включены в документацию.

Проверки: два совпадения до изменения, два успешных bcrypt.compare после итогового изменения, ровно 8 букв/цифр, уникальность паролей, неизменность остальных полей JSON, исключение файлов с секретами из Git. Проверка через HTTP не выполнялась: приложение не запускалось, миграции не выполнялись; проверен фактический bcrypt-механизм авторизации на сохранённых хешах.

Схема, API и код приложения не изменены. Роли, заказы и сессии сохранены; существующие сессии не отозваны. Analysis и удалённая БД не затрагивались. Локальная БД после проверки остановлена, как до операции. Build и unit tests не требуются для изменения только учётных данных.

Откат возможен по отдельному запросу из защищённых локальных копий в testData/.password-rotation-backup-*.json: выбрать состояние до первой ротации, восстановить только соответствующие хеши и исходный dev.json. Резервные копии в Git не добавлять.
