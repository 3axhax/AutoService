# Поправить всплывающее меню

Дата: 2026-11-02. Ветка: 0004-mobile-guest-menu.

Цель: неавторизованный пользователь мобильной версии может скрыть и повторно открыть меню так же, как работник. Desktop guest header и существующие права/пункты меню авторизованных пользователей сохраняются.

Воспроизведение: встроенный браузер, http://localhost:5173/, guest, viewport 390×844. После закрытия модального входа меню занимает почти весь экран, контент MainPage перекрыт, кнопки скрытия нет. Источник: widgets/navigation/ui/Navigation.tsx передаёт canCollapsed только для worker; NavigationUI.tsx использует его для transform и обеих кнопок.

Решение: отдельный необязательный флаг мобильного сворачивания в существующем NavigationUI для guest. Использовать существующий Redux hideNavigation/localStorage; desktop-ограничение оставить на прежнем canCollapsed, гостевые toggle-кнопки скрывать через lg:hidden. Не добавлять отдельное меню или hook определения размера. Добавить доступные подписи кнопок.

Этапы: изменить Navigation/NavigationUI; проверить мобильное закрытие/открытие, доступ к входу, повторное закрытие, reload и desktop; выполнить client build, git diff --check и статус контейнеров. Автоматического UI harness в client нет, регрессия фиксируется воспроизведением и проверкой реального браузера.

API, БД, авторизация, заказы, схема и миграции не меняются; backup не требуется. Server/production/Analysis не затрагивать. Откат — вернуть два frontend-файла, миграция данных не нужна. Риск — случайно скрыть desktop guest menu или изменить worker collapse; проверить CSS-ветки и браузер на мобильной и desktop ширине.

Приёмка: guest контент доступен при скрытом меню; кнопки открыть/скрыть работают; вход открывается; настройка сохраняется при reload; на desktop гостевое меню видно без кнопки скрытия.

2026-11-02, уточнение пользователя: при выборе пункта мобильного меню автоматически сворачивать его. Иначе отдельный клик сворачивания воспринимается модальным входом как outside click и закрывает форму. Добавить общий обработчик выбора для обычных ссылок, action-кнопок и пунктов dropdown; открытие dropdown само по себе меню не закрывает. Сворачивание выполнить в том же событии, перед открытием модалки. Ширину проверять через matchMedia на момент клика (граница 1024px), не полагаться на Redux deviceType, который инициализируется desktop и обновляется лишь при resize. Desktop не сворачивать автоматически.
