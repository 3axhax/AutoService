# Результат

В локальной БД компании 3 добавлены две общие цены: пакеты на 4 колеса и медная смазка по 100 ₽. Груз и гранулы остались по 450 и 650 ₽. Все четыре материала доступны обоим типам транспорта; количество умножает цену, скидка применяется по существующему правилу. Существующие заказы не пересчитывались.

Добавлена транзакционная миграция с проверкой конфликтов и отметкой выполнения; справочные данные обновлены для новых баз. API и схема не меняются. Откат требует проверить текущие строки, удалить только добавленные цены с их условиями и отметку миграции; остальные данные не затрагивать. Перед локальным изменением создан архив в tmp/backups, проверенный pg_restore --list и полным чтением, восстановление отдельно не проверялось.

Сборка backend и 215 тестов backend прошли; калькулятор — 38 тестов, включая четыре материала для обоих типов транспорта, количества и скидку. Повторный запуск и конфликт проверены unit-тестами миграции. В локальной БД по одной цене на материал и одна отметка миграции; контейнеры работают, БД healthy. Ручной сценарий формы и отдельное испытание восстановления/миграции на копии не проводились. Рабочий сервер не изменялся.

2026-11-06 пользователь принял задачу и запросил поставку на рабочий сервер. Поставка включает штатную миграцию цен после проверки серверной БД и резервной копии.
