# Корректировка автопрокрутки

Цель: при вводе текста в параметр заказа типа INPUT карусель остаётся на месте; автоматический переход при первом выборе SELECT сохраняется.

Сейчас `client/src/features/editOrderForm/ui/SwitchParameterType.tsx` вызывает `carousel.next(1)` при первом изменении INPUT или SELECT. Воспроизведение: открыть незаполненную форму заказа и ввести первый символ в текстовое поле — карусель сдвигается на один слайд.

Решение: ограничить условие перехода типом SELECT. Изменяется только клиентский компонент; API, таблицы, данные и конфигурация не меняются. Авторизация, сохранение заказа и расчёт цены не затрагиваются. Миграция не требуется; откат — вернуть прежнее условие.

Проверка: сборка и тесты клиента, проверка состояния контейнеров и diff. При доступности окружения — проверить ввод INPUT и первый выбор SELECT в форме. Риск: прежний автоматический переход для SELECT должен сохраниться.
