# Выгрузка смен работника

Цель: работник скачивает Excel со списком заказов по фильтру истории смен либо одной выбранной смены; структура файла совпадает с выгрузкой администратора. Изначально период истории — с первого числа текущего месяца по сегодня, как у администратора.

Текущее состояние: `client/src/pages/workerShiftsHistory/WorkerShiftsHistoryPage.tsx` и `ShiftsListItem.tsx` не имеют экспорта, `entities/shifts/model/slice.ts` задаёт пустой интервал. `server/src/orders/orders.controller.ts` защищает существующий downloadList только для ADMIN; `orders.service.ts` формирует файл и загружает заказы отдельно. Фильтр смен в `shifts.service.ts` действует по дате окончания и включает открытую смену, если сегодняшний день входит в интервал.

Решение: использовать общую серверную сборку Excel для администратора и работника, при выборке работника ограничить данные текущей компанией и владельцем смены; экспорт всех отфильтрованных смен без постраничного ограничения и отдельный экспорт конкретной смены, независимо от фильтра. Кнопки рядом с фильтром и в карточке не должны вызывать раскрытие карточки. Уточняется состав открытых смен и дополнительных работ. Существующий интерфейс и фильтры администратора сохранить. DTO и защищённые маршруты по существующим паттернам, без изменений схемы и записей БД.

Проверка: backend unit/integration/HTTP с ограничением чужих смен и компаний, валидацией, диапазоном и проверкой workbook, тесты клиента, сборки и browser smoke. Риск утечки чужих заказов, несовпадения списка и экспорта, потери всех строк за пределами страницы, конфликта кликов и текущего состояния сессии; проверить негативные сценарии. Откат — возврат изменения кода; миграции и изменения данных не требуются.

Уточнение 2026-11-06: общая выгрузка следует текущему отбору истории, включая открытую смену, когда текущий день входит в интервал. Выгрузки работника включают дополнительные работы на отдельном листе; администраторский лист заказов сохраняет текущий формат. Индивидуальная выгрузка включает только данные выбранной смены.

2026-11-06: пользователь запросил имя Shifts_{имя}_{интервал}.xlsx, даты в формате ГГГГ_ММ_ДД, одинаковые границы — одна дата. Предположение до ответа на уточнение: для смены период её начала и окончания (для открытой до сегодня); без фильтра суффикс «все». Недопустимые в файловых именах символы заменяются на подчёркивание.

Уточнение пользователя: для отдельной закрытой смены в имени указывается только дата закрытия, для открытой — только дата начала; для пустого фильтра — «все». Это заменяет ранее записанное предположение.
